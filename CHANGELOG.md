# Changelog

## 0.3.1 - 2026-09-19

- Force an opaque application background instead of inheriting transparent GTK theme colors.
- Group duplicate processes into expandable application rows.
- Hide most system/background processes from the default process view.
- Add Advanced View for lower-level process visibility.
- Improve End Task behavior for grouped user processes.
- Improve GPU model detection and performance details.
- Add CPU, memory, GPU, and network performance sections.
